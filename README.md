# HottSneakers - Sistema de Gerenciamento de Tênis

##  Sobre o Projeto

O **HottSneakers** é um sistema completo de gerenciamento de tênis e anúncios, desenvolvido como projeto da disciplina de **Desenvolvimento Web Mobile** da **Universidade Federal do Tocantins (UFT) - Campus Palmas**.

Este projeto consiste em uma aplicação híbrida que integra um sistema web administrativo com um aplicativo mobile, permitindo o cadastro, visualização, edição e exclusão de tênis, além de funcionalidades para criação e gerenciamento de anúncios.

##  Tecnologias Utilizadas

### Backend (Sistema Web)
- **Python 3.x**
- **Django** - Framework web
- **Django REST Framework** - API RESTful
- **SQLite** - Banco de dados
- **Bootstrap 5** - Framework CSS

### Frontend Mobile
- **Ionic 7** - Framework híbrido
- **Angular** - Framework JavaScript
- **TypeScript** - Linguagem de programação
- **Capacitor** - Runtime nativo
- **Node.js** - Ambiente de execução

### Ferramentas e Bibliotecas
- **Git** - Controle de versão
- **VS Code** - Editor de código
- **Ionic Storage** - Armazenamento local
- **Capacitor HTTP** - Requisições HTTP

##  Como Executar

### Backend (Django)
```bash
cd sistema
python manage.py runserver
```

### Mobile (Ionic)
```bash
cd sistema-mobile
npm install
npm start
```
